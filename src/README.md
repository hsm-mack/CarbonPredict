# Código-fonte

Esta pasta receberá funções reutilizáveis do projeto, por exemplo:

- `data_collection.py` — coleta/importação;
- `data_cleaning.py` — limpeza e padronização;
- `features.py` — criação de atributos temporais;
- `models.py` — treinamento e previsão;
- `evaluation.py` — métricas e avaliação.

Na Etapa 1, esta estrutura fica preparada para as etapas seguintes.
